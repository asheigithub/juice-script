getDefinitionByName()function
public function getDefinitionByName(param1:String):*

返回 name 参数指定的类的类对象引用。

Parameters

param1:String — 类的名称。

Returns
* — 参数指定的类的类对象引用。

Example
下面代码演示如何使用字符串来查找并创建类型 
import flash.utils.getDefinitionByName;
var m = getDefinitionByName("juice.geom.Vector2");
var b = new m(1, 1);
trace( b.length );  // 1.414

public function getQualifiedClassName(value:*):String

返回对象的完全限定类名。

Parameters

value:* — 需要完全限定类名称的对象。可以将任何 ActionScript 值传递给此方法，包括所有可用的 ActionScript 类型、对象实例、原始类型（如 uint）和类对象。

Returns
String — 包含完全限定类名称的字符串。
